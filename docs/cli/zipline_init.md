## zipline init

Print the shell hook script (add eval "$(zipline init zsh)" to your rc file)

```
zipline init <bash|zsh> [flags]
```

### Options

```
      --cmd string   wrapper function name (default from config, else zl)
      --funcs-only   emit only the per-alias functions (used for refresh)
  -h, --help         help for init
```
